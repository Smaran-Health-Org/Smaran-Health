How to read this

  • × = total ÷ audio length. Below 1.0 means faster than playback; lower is better.
  • provider is Sarvam's own work. overhead is everything we control. Fix overhead first.
  • first text only exists for hybrid. It is when the doctor could start reading.
  • If first text ≈ total, the hybrid preview adds no value on that clip.
  • turns must be greater than 0. Zero means diarization failed or no speech was detected.
  • Median is used, and failed runs are excluded. Compare rows with the same mode and length.
